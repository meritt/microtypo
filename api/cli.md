# CLI

Команда `microtypo` — фильтр stdin→stdout с теми же опциями, что и у библиотеки.

```bash
echo '"Амбер" -- вечен' | microtypo
microtypo --config config/microtypo.json < draft.md
microtypo --html --entities < post.md
microtypo --write content/post.md
```

## Опции

| Флаг                                                                 | Описание                                                                                        |
| -------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `--html` / `--no-html`                                               | главный переключатель выдачи разметки (по умолчанию выкл — обычный текст)                       |
| `--entities` / `--no-entities`                                       | глифы как HTML-сущности вместо обычного Unicode                                                 |
| `--input <text\|html\|markdown\|json\|xml\|yaml\|toml\|frontmatter>` | формат ввода (по умолчанию `text`)                                                              |
| `--hanging` / `--no-hanging`                                         | оптическое выравнивание кавычек и скобок (`hanging.quote` + `hanging.bracket`)                  |
| `--rule <id=bool>`                                                   | включает или отключает правило по идентификатору (можно указывать многократно)                  |
| `--render <key=value>`                                               | опция вывода разметки, например `nowrap=nobr` или `hanging=class` (можно указывать многократно) |
| `--max-input <n>`                                                    | отклонять ввод длиннее `n` символов                                                             |
| `--max-ms <n>`                                                       | бюджет обработки по времени в миллисекундах                                                     |
| `--set <path=value>`                                                 | произвольный путь в конфиге (можно указывать многократно)                                       |
| `--config <path>`                                                    | JSON-файл конфигурации (отключает автообнаружение)                                              |
| `-w`, `--write`                                                      | перезаписать указанные файлы на месте                                                           |
| `-o`, `--output-file <path>`                                         | записать результат в файл                                                                       |
| `-h`, `--help`                                                       | показать справку                                                                                |
| `--version`                                                          | вывести версию                                                                                  |

`--rule`, `--render` и `--set` принимают пары `key=value` и приводят `true`, `false` и числа к нужному типу:

```bash
microtypo --rule 'punctuation.period_at_end=true' --rule 'quote.*=false' < in.txt
microtypo --render 'hanging=class' --render 'nowrap=nobr' < in.txt
microtypo --set 'render.hanging=class' --set 'maxInputLength=50000' < in.txt
```

## Ввод и вывод

- **Без файлов** — читает stdin, пишет в stdout (или `--output-file`). На терминале, где файлы не заданы, выводит справку.
- **Один файл** — читает его, пишет в stdout (или `--output-file`), если только `--write` не перезаписывает его на месте.
- **Несколько файлов** — требуют `--write`; каждый перезаписывается на месте.

`--write` и `--output-file` взаимно исключают друг друга, а `--output-file` нельзя сочетать с несколькими файлами. Файл или поток, чей размер превышает `maxInputLength × 3` байт, отклоняется до чтения: UTF-8 кодирует любой символ не более чем тремя байтами, поэтому такой ввод заведомо не пройдёт проверку длины.

Завершающий перенос строки сохраняется: если ввод заканчивался переносом, переносом заканчивается и вывод — иначе каждая перезапись через `--write` съедала бы последнюю строку файла. Вид переноса берётся не у ввода, а у тела вывода: движок приводит внутренние `\r\n` к `\n`, поэтому обычный многострочный документ заканчивается тем же `\n`, что и все его строки (`a\r\nb\r\n` даёт `a\nb\n`). Исходный `\r\n` возвращается там, где голого `\n` в выводе нет.

### Запись на месте

`--write` и `--output-file` заменяют файл атомарно: результат пишется во временный файл в той же директории и переносится на место через `rename()`. Читатель видит либо прежнее содержимое, либо новое, но никогда не половину. Отсюда правила:

- **Symlink разыменовывается** — записывается файл, на который указывает ссылка; сама ссылка остаётся ссылкой. Ссылка, чья цель удалена, — ошибка использования (код `2`).
- **Запись не покидает рабочую директорию.** Путь, названный внутри рабочей директории, но ведущий наружу через ссылку, — ошибка использования (код `2`). Путь, названный снаружи (`--write ../other/x.md`, `--output-file /tmp/out.html`), работает как обычно; чтения это не касается, оно идёт по ссылке всегда.
- **Права и режим.** Права на файл (`0444` — «не переписывать») и на директорию проверяются до первой записи; временный файл создаётся с правами цели, а не с умолчанием под `umask`.
- **Отказ на подготовительной фазе не трогает ни одного файла:** все цели сначала читаются, обрабатываются и проверяются, и только потом начинается запись.
- **Батч не транзакция.** Отказ во время самой записи — отказ устройства, подменённая директория — оставляет уже переписанные файлы переписанными. Отката нет.

## Приоритет конфигурации

От низкого к высокому:

1. Значения движка по умолчанию.
2. `.microtyporc.json` — автоматически обнаруживается обходом директорий вверх от текущей либо задаётся через `--config` (что отключает автообнаружение). JSON [формы конфигурации](configuration.md).
3. Флаги командной строки.

## Коды выхода

| Код | Значение                                         |
| --- | ------------------------------------------------ |
| `0` | успех                                            |
| `1` | ошибка выполнения (слишком большой ввод, бюджет) |
| `2` | ошибка использования или конфигурации            |
