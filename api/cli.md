# CLI

`microtypo` — фильтр stdin→stdout с опциями библиотеки; файлы, каталоги и маски обрабатываются с записью на месте, проверкой или diff.

```bash
echo '"Амбер" -- вечен' | microtypo
microtypo --config config/microtypo.json < draft.md
microtypo --stdin-filepath post.md --entities < post.md
microtypo --write content/post.md
```

## Опции

| Флаг                                                                             | Описание                                                                                        |
| -------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| `--html` / `--no-html`                                                           | главный переключатель разметки (по умолчанию выключен — обычный текст)                          |
| `--entities` / `--no-entities`                                                   | глифы как HTML-сущности вместо обычного Unicode                                                 |
| `--input <text\|html\|plain\|markdown\|mdx\|json\|xml\|yaml\|toml\|frontmatter>` | явно задаёт формат ввода                                                                        |
| `--stdin-filepath <path>`                                                        | виртуальный путь stdin для формата, overrides и исключений                                      |
| `--hanging` / `--no-hanging`                                                     | оптическое выравнивание кавычек и скобок (`hanging.quote` + `hanging.bracket`)                  |
| `--rule <id=bool>`                                                               | включает или отключает правило по идентификатору (можно указывать многократно)                  |
| `--render <key=value>`                                                           | опция вывода разметки, например `nowrap=nobr` или `hanging=class` (можно указывать многократно) |
| `--max-input <n>`                                                                | отклонять ввод длиннее `n` единиц UTF-16; по умолчанию и не больше `5_000_000`                  |
| `--max-ms <n>`                                                                   | бюджет обработки в миллисекундах; по умолчанию `5_000`, `0` выключает                           |
| `--set <path=value>`                                                             | произвольный путь в конфиге (можно указывать многократно)                                       |
| `--config <path>`                                                                | JSON-файл конфигурации (отключает автообнаружение)                                              |
| `-w`, `--write`                                                                  | перезаписать указанные файлы на месте                                                           |
| `--check`                                                                        | вывести координаты правок, код 1 при их наличии                                                 |
| `--diff`                                                                         | вывести унифицированный diff                                                                    |
| `--explain`                                                                      | вывести trace правил в stderr                                                                   |
| `-o`, `--output-file <path>`                                                     | записать результат в файл                                                                       |
| `-h`, `--help`                                                                   | показать справку                                                                                |
| `--version`                                                                      | вывести версию                                                                                  |

`--rule`, `--render` и `--set` принимают `key=value`; `true`, `false` и числа приводятся к типу, остальное остаётся строкой. `--set` делит путь по точкам, поэтому идентификаторы правил задают через `--rule`.

```bash
microtypo --rule 'punctuation.period_at_end=true' --rule 'quote.*=false' < in.txt
microtypo --render 'hanging=class' --render 'nowrap=nobr' < in.txt
microtypo --set 'render.hanging=class' --set 'maxInputLength=50000' < in.txt
```

## Ввод и вывод

- **Без файлов** — stdin в stdout или `--output-file`. Если stdin — терминал, выводит справку. `--write` требует файлов.
- **Один файл** — в stdout или `--output-file`; `--write` перезаписывает его.
- **Несколько файлов** — только с `--write`, `--check` или `--diff`. Пути сортируются лексикографически, повторы обрабатываются один раз.

`--write` и `--output-file` несовместимы. Файл или поток больше `maxInputLength × 3` байт отклоняется до чтения: UTF-8 кодирует единицу UTF-16 не более чем тремя байтами.

Завершающий перенос строки сохраняется. Движок приводит `\r\n` к `\n`, поэтому вид переноса берётся из вывода: `a\r\nb\r\n` даёт `a\nb\n`, а `\r\n` остаётся, только если `\n` в выводе нет (`a\r\n` даёт `a\r\n`).

### Запись на месте

`--write` и `--output-file` пишут во временный файл в той же директории и заменяют цель через `rename()`: читатель видит прежнее или новое содержимое, но не частично записанное.

- **Символьная ссылка разыменовывается:** переписывается цель, ссылка остаётся ссылкой. Ссылка на несуществующую цель и несуществующая директория цели — код `2`.
- **Ссылка не выводит запись за рабочую директорию:** путь внутри неё, ведущий наружу через ссылку, — код `2`. Путь, заданный снаружи (`--write ../other/x.md`, `--output-file /tmp/out.html`), пишется как обычно. Чтение идёт по ссылкам без ограничений.
- **Права** на файл (`0444` — «не переписывать») и на директорию проверяются до первой записи; временный файл получает права цели, а не умолчание под `umask`.
- **Файл без правок** `--write` не переписывает: содержимое, время изменения и права не меняются, `0444` на нём не останавливает пакет.
- **Отказ до записи не трогает ни одного файла:** все цели читаются, обрабатываются и проверяются до первой записи.
- **Пакет не транзакционен:** сбой во время записи оставляет уже переписанные файлы, отката нет.

## Приоритет конфигурации

От низкого к высокому:

1. Значения движка с `maxInputLength` `5_000_000` вместо библиотечного `30_000` и формат по расширению пути.
2. `.microtyporc.json` — [конфигурация библиотеки](configuration.md) с дополнительным полем `overrides`; ищется вверх от рабочей директории либо задаётся `--config`.
3. Совпавшие `overrides` в порядке перечисления.
4. Флаги командной строки.

Строковое `input` любого слоя (`--input markdown`, `"input": "markdown"`) меняет только формат: остальные поля `input` нижних слоёв сохраняются.

Формат по расширению, без учёта регистра: `.md`, `.markdown` — `markdown`; `.mdx` — `mdx`; `.html`, `.htm` — `html`; `.json` — `json`; `.xml`, `.svg` — `xml`; `.yaml`, `.yml` — `yaml`; `.toml` — `toml`; остальные — `text`. `frontmatter` задаётся только явно. stdin без `--stdin-filepath` — `text` без path overrides. Виртуальный путь не читается с диска и несовместим с файловыми аргументами.

```json
{
  "overrides": [
    { "files": "content/**/*.md", "options": { "input": "frontmatter" } },
    {
      "files": ["content/drafts/**"],
      "exclude": "**/published.md",
      "options": { "rules": { "quote.*": false } }
    }
  ]
}
```

Маски `files` и необязательного `exclude` — строка или массив строк — считаются от каталога конфигурации и сопоставляются `path.matchesGlob`. `options` проверяются схемой библиотеки поверх основного конфига; объекты объединяются рекурсивно, массивы заменяются.

## Каталоги, маски и исключения

- **Каталог** обходится рекурсивно, берутся только документы разметки: `.md`, `.markdown`, `.mdx`, `.html`, `.htm`.
- **Аргумент, которого нет на диске,** — маска `fs.promises.glob` от рабочей директории; она выбирает все расширения из списка форматов выше: `microtypo --write 'locales/**/*.json'`. В shell маску берут в кавычки.
- **Явный файл** принимается с любым расширением.
- Пропускаются `node_modules`, `.git` и `.microtyporc.json`. Обход и маска не следуют по символьным ссылкам — ни на каталоги, ни на файлы; по ссылке идёт только явно названный путь.
- Маска без совпадений — код `2`; пустой каталог или полностью исключённый набор — код `0` без вывода.

`.microtypoignore` читается из каталога конфигурации, без неё — из рабочей директории. Это подмножество gitignore: пустые строки и строки с `#` в начале пропускаются, `!` возвращает путь, побеждает последняя совпавшая строка; `*`, `?`, `**` и классы символов сопоставляются `path.matchesGlob`. Начальный `/` привязывает маску к корню, маска без `/` совпадает на любой глубине, конечный `/` означает содержимое каталога. Пробелы по краям строки снимаются. Вложенных ignore-файлов, экранирования, braces и extglob нет: такой синтаксис — код `2`. В отличие от gitignore, `!` возвращает файл и внутри исключённого каталога. Исключения действуют на явные файлы и на `--stdin-filepath`: stdin на исключённом пути выводится без изменений.

Обход ограничен 30 секундами и `100_000` найденными записями (проверка на каждом результате glob; выполняющийся вызов файловой системы таймер не прерывает), набор — `10_000` файлами, суммарный вход пакета — `50_000_000` единиц UTF-16. Всё проверяется до записи; превышение лимитов обхода и числа файлов — код `2`, суммарного входа — код `1`. Одиночный файл и stdin ограничены `maxInputLength`.

## Коды выхода

`--check` пишет в stdout `файл:строка:столбец` на каждую правку: строка и столбец с 1, столбец в единицах UTF-16 входа, имя stdin — `<stdin>` или путь `--stdin-filepath`. Возвращает `1`, если правки есть.

`--diff` пишет в stdout унифицированный diff, один полный блок на изменённый файл; нет LF в конце — строка `\ No newline at end of file`. Возвращает `0`. Пути с пробелами применяет `patch -p1`; управляющие символы, кавычки и обратная косая черта в пути записываются в C-форме Git, такие патчи применяет `git apply -p1`. `--check` и `--diff` только читают и несовместимы друг с другом, с `--write` и `--output-file`.

`--explain` не меняет вывод и пишет в stderr по JSON-строке `{ "file": "путь", "trace": [...] }` на файл; формат — в [диагностике](extending.md#диагностика). Совместим с `--check`, `--diff` и `--write`.

| Код | Значение                                                                 |
| --- | ------------------------------------------------------------------------ |
| `0` | успех                                                                    |
| `1` | ошибка выполнения (слишком большой ввод, бюджет) либо правки в `--check` |
| `2` | ошибка использования или конфигурации                                    |
