# Правила

Двенадцать встроенных групп выполняются в фиксированном порядке:

```
quote → dash → symbol → punctuation → number → space → abbr → nobr → date → hanging → other → text
```

Правило переключается по идентификатору `группа.правило` через [`rules`](configuration.md#2-правила); там же селекторы, маски, наборы и порядок ключей:

```js
microtypo(text, {
  rules: { 'punctuation.comma_before_conjunction': true, 'text.paragraphs': false }
});
```

Флаги: `off` — выключено по умолчанию; `cycled` — повторяется, пока текст меняется, не более 100 итераций; `html` — работает только при `html: true`.

Пример — вход и вывод при конфигурации по умолчанию с включённым правилом; без правила вывод другой. Нужная примеру опция указана в скобках. `⍽` — неразрывный пробел, `⎵` — узкий неразрывный пробел, `␣` — пробел на краю строки, `\n` — перевод строки.

## Строчная разметка

Правила пробелов читают видимый текст по обе стороны строчного тега и вставляют, убирают или заменяют пробел сквозь него, сохраняя границы выделения:

```js
microtypo('<p>Он в <em>доме</em> и <a href="/x">саду</a>, 10 <b>кг</b>.</p>', { html: false });
// '<p>Он⍽в⍽<em>доме</em> и⍽<a href="/x">саду</a>, 10⍽<b>кг</b>.</p>'

microtypo('Он в *доме* и [саду](/x).', { input: 'markdown', html: false });
// 'Он⍽в⍽*доме* и⍽[саду](/x).'
```

- Строчная разметка — теги HTML, кроме блочных и `<br>` (включая `<a>`), в форматах `html`, `text` и `markdown`; в Markdown ещё маркеры выделения (`*`, `_`, `**`, `__`, `~~`) там, где Markdown признаёт их выделением, и ссылки `[текст](цель)`, `[текст][метка]`: текст видимый, цель и метка возвращаются байт в байт.
- Защищённый строчный элемент (`<code>`, `<kbd>`, код в обратных кавычках) — одно слово, содержимое не меняется: `Он в <code>x</code>` → `Он⍽в⍽<code>x</code>`. Элемент, приклеенный к кавычке, которая с другой стороны приклеена к слову, читается как написано: `"о да"<code>x</code>` → `«о⍽да»<code>x</code>`.
- Тег остаётся у того же видимого символа: пробел снаружи элемента остаётся снаружи, внутри — внутри.
- Границы, как и без разметки: блочные теги, `<br>`, `<img>` и другие одиночные теги, комментарии, переводы строк, границы значений в форматах данных, защищённые блоки.
- Разметка читается как написано, если у тега нет пары, если у тега пробел с внутренней стороны (`<b> слово</b>`) или тег стоит между пробелами.
- Разметку движка (обёртки `nowrap`, `<sup><small>`, `<sub><small>`, автоссылки) повторный проход по выводу оставляет на месте.
- Замена слов учитывает границу тега: `5 <i>руб.</i>` не меняется, `5 руб.` → `5⍽₽.`; пробел между знаком и выделенным словом меняется сквозь разметку: `(c) <s>Амбер</s>` → `©⍽<s>Амбер</s>`.
- При `html: true` обёртка `nowrap` ставится вокруг целых элементов автора: `и <i>т.д.</i>` → `<span style="white-space:nowrap;">и <i>т. д.</i></span>`. Если слова обёртки ровно держит элемент автора, они связываются NBSP внутри него (`<b>и⍽т.⍽д.</b>`); неразрывный элемент автора (`<nobr>`, `<span>` с `nowrap`) не меняется. Если обёртка пересекла бы границу элемента (`<b>Он и</b> т.д.`), слова связываются NBSP без обёртки.
- Пользовательские группы правил видят разметку как написано.

## quote — Кавычки

| Правило           | Что делает                                                             | Пример                                                          | Флаги |
| ----------------- | ---------------------------------------------------------------------- | --------------------------------------------------------------- | ----- |
| `around_link`     | Выносит кавычки за `<a>`                                               | `<a href="/amber">"Амбер"</a>` → `«<a href="/amber">Амбер</a>»` |       |
| `fix_orphan_open` | `«`, приклеенная к концу слова перед пробелом или концом текста, → `»` | `«Корвин« ушёл` → `«Корвин» ушёл`                               |       |
| `open`            | Открывающая кавычка                                                    | `"Амбер` → `«Амбер`                                             |       |
| `open_cyrillic`   | Кавычка, приклеенная к кириллице, → `«` с пробелом перед ней           | `город"Амбер` → `город «Амбер`                                  |       |
| `close`           | Закрывающая кавычка                                                    | `«Амбер"` → `«Амбер»`                                           |       |
| `nested`          | Вложенные кавычки → „лапки“, `"` после цифры → `″`                     | `«Принц «Корвин» ушёл»` → `«Принц „Корвин“ ушёл»`               |       |

Настройки `quote.nested` и `quote.inch` — в [Конфигурации](configuration.md#настройки-кавычек). Открывающая кавычка может стоять в конце строки: `Он сказал: "\nПривет\nмиру"` → `Он⍽сказал: «\nПривет\nмиру»`; через пустую строку кавычки не парятся. URL в конце цитаты не забирает закрывающую кавычку: в `«цитата „https://example.com“ дальше»` при `html: true` `href` — `https://example.com`.

## dash — Дефисы и тире

| Правило                | Что делает                                             | Пример                                              | Флаги |
| ---------------------- | ------------------------------------------------------ | --------------------------------------------------- | ----- |
| `em_triple_hyphen`     | Три дефиса между русскими словами → тире               | `Корвин---принц` → `Корвин⍽— принц`                 |       |
| `em_double_hyphen`     | Двойной дефис → тире                                   | `Корвин -- принц` → `Корвин⍽— принц`                |       |
| `en_range`             | Диапазон чисел с пробелами вокруг дефиса → `–`         | `12 - 19` → `12–19`                                 |       |
| `em`                   | Тире после слова, кавычки, скобки или знака препинания | `Корвин - принц` → `Корвин⍽— принц`                 |       |
| `em_line_start`        | Тире в начале строки                                   | `- Стой` → `—⍽Стой`                                 |       |
| `em_after_sentence`    | Тире после `!`, `?` и многоточия                       | `Стой! - крикнул Корвин` → `Стой! —⍽крикнул Корвин` |       |
| `compound_preposition` | Дефис в составных предлогах: из-за, из-под             | `Вышел из за леса` → `Вышел из-за леса`             |       |
| `indefinite_pronoun`   | Дефис в неопределённых местоимениях                    | `Пришёл кто то` → `Пришёл кто-то`                   |       |
| `hyphenated_particle`  | Дефис с частицами: кое-как, кой-кого, всё-таки         | `всё таки пришёл` → `всё-таки пришёл`               |       |
| `emphatic_particle`    | Дефис с частицами -ка, -кась, -тка, -тко, -де          | `скажи ка` → `скажи-ка`                             |       |

- `em_triple_hyphen`: слова от двух букв в одной строке, с пробелами вокруг `---` или без. Разделители Markdown, ограды YAML, четыре дефиса, числа и латинские идентификаторы не меняются.
- `en_range` и `em` не трогают дефис между операндами, если один из них через пробелы соседствует с `=`: `x = 5 - 3`, `10 - 2 = 8`, `a = b - c`, `(x = 5 - 3)`. Операнд кончается на первом знаке, который не буква и не цифра, поэтому `пути - $W = …` и `title = «Амбер - город»` получают тире.

## symbol — Специальные символы

| Правило            | Что делает                           | Пример                            | Флаги    |
| ------------------ | ------------------------------------ | --------------------------------- | -------- |
| `plus_minus_slash` | `+/-` → `±`                          | `+/-5` → `±5`                     |          |
| `arrows_extended`  | `<->` → `↔`, `=>` → `⇒`, `<=>` → `⇔` | `Амбер <-> Хаос` → `Амбер ↔ Хаос` |          |
| `trademark`        | `(tm)` → `™`                         | `Amber(tm)` → `Amber™`            |          |
| `registered`       | `(R)` → `®`                          | `Windows(R)` → `Windows®`         |          |
| `copyright`        | `(c)` → `©`                          | `(c) 2024` → `©⍽2024`             |          |
| `apostrophe`       | Типографский апостроф                | `Жанна д'Арк` → `Жанна д’Арк`     | `cycled` |
| `fahrenheit`       | Градусы Фаренгейта                   | `451F` → `451⍽°F`                 |          |
| `arrows`           | `->` → `→`, `<-` → `←`               | `Амбер -> Хаос` → `Амбер → Хаос`  |          |

- `plus_minus_slash`: отдельное `+/-` и `+/-` перед числом; `x+/-y` не меняется.
- `arrows_extended` выполняется до `arrows` и меняет только отдельные стрелки: `x<->y`, `a=>b`, `==>`, `<-->` не меняются. Без него `arrows` и `number.math` оставляют `a <-> b`, `a <=> b`, `a <== b` как набрано.
- `copyright` ставит `©`, если за `(c)` через необязательный пробел идёт год или слово с заглавной (`(c) 2024`, `(c) Амбер`) либо перед `(c)` стоит `Copyright` в любом регистре. Не меняются: `f(c)`, `вариант (c)` и `(c)` в абзаце, где раньше стоят `(a)`, `(b)` или `(а)`, `(б)`; абзац кончается пустой строкой или закрывающим блочным тегом.
- `registered` ставит `®` после слова от двух букв с заглавной, вплотную или через пробелы: `iPhone(R)` → `iPhone®`. `f(r)`, `sin(r)`, `радиус (r)` не меняются.

## punctuation — Пунктуация

| Правило                       | Что делает                                           | Пример                                                           | Флаги    |
| ----------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------- | -------- |
| `comma_before_conjunction`    | Запятая перед «а» и «но»                             | `Корвин ушёл а Рэндом остался` → `Корвин ушёл, а⍽Рэндом остался` | `off`    |
| `repeat_limit`                | `!` и `?` — один или три: `!!` → `!`, `!!!!` → `!!!` | `Стой!!!!` → `Стой!!!`                                           |          |
| `collapse_repeated`           | Повторные запятые, двоеточия, точки с запятой        | `Корвин,, Рэндом` → `Корвин, Рэндом`                             | `cycled` |
| `ellipsis`                    | Три и более точки → `…`                              | `Корвин ушёл...` → `Корвин⍽ушёл…`                                |          |
| `mark_ellipsis`               | `?…` → `?..`, `!…` → `!..`                           | `Кто там?…` → `Кто⍽там?..`                                       |          |
| `swap_exclamation_question`   | `!?` → `?!`                                          | `Кто там!?` → `Кто⍽там?!`                                        |          |
| `drop_terminal_garbage`       | Лишняя пунктуация после конечного знака              | `Стой!,!` → `Стой!`                                              |          |
| `collapse_doubled`            | Сдвоенные знаки → одиночные                          | `Корвин ушёл!.` → `Корвин⍽ушёл!`                                 |          |
| `trim_bracket_terminal_punct` | Случайная пунктуация перед `)`                       | `(Корвин ушёл,)` → `(Корвин⍽ушёл)`                               |          |
| `bracket_spaces`              | Пробелы внутри скобок                                | `( Корвин )` → `(Корвин)`                                        |          |
| `space_before_bracket`        | Пробел перед `(`                                     | `Корвин(принц)` → `Корвин (принц)`                               |          |
| `period_at_end`               | Точка в конце текста, если её нет                    | `Корвин ушёл` → `Корвин⍽ушёл.`                                   | `off`    |

- После точки распознанного сокращения `?` или `!` сохраняется: `Ждал 5 сек.!` не меняется; после обычного слова лишний знак удаляется: `Он ушёл.!` → `Он⍽ушёл.`.
- `space_before_bracket` отбивает скобку только от русского слова; пустая пара `()`, слово из латиницы и цифр и `(c)` не отбиваются: `render()`, `слово()`, `printf(x)`, `Amber(город)`, `слово(c) Амбер` не меняются.

## number — Числа, дроби, математические знаки

| Правило             | Что делает                                             | Пример                                                       | Флаги  |
| ------------------- | ------------------------------------------------------ | ------------------------------------------------------------ | ------ |
| `prime`             | Апостроф после отдельного числа → `′`                  | `5' 10″` → `5′ 10″`                                          |        |
| `fraction_extended` | `1/3`, `2/3`, `1/8`, `3/8`, `5/8`, `7/8` → ⅓ ⅔ ⅛ ⅜ ⅝ ⅞ | `1/3 пути` → `⅓⍽пути`                                        |        |
| `minus`             | Минус у отрицательного числа                           | `-5` → `−5`                                                  |        |
| `time`              | Без пробелов вокруг двоеточия во времени               | `08 : 59` → `08:59`                                          |        |
| `en_range`          | `–` в диапазоне чисел                                  | `100-500` → `100–500`                                        |        |
| `minus_range`       | Минус в диапазоне через многоточие                     | `-5…10` → `−5…10`                                            |        |
| `times`             | `×` в размерах                                         | `6х7x9` → `6×7×9`                                            |        |
| `sub`               | Нижний индекс                                          | `x_1` → `<p>x<sub><small>1</small></sub></p>` (`html: true`) | `html` |
| `sup`               | Верхний индекс                                         | `м^2` → `<p>м<sup><small>2</small></sup></p>` (`html: true`) | `html` |
| `fraction`          | `1/2`, `1/4`, `3/4` → ½ ¼ ¾, кроме дюймов              | `1/2 пути` → `½⍽пути`                                        |        |
| `math`              | `!=`, `<=`, `>=`, `~=`, `+-` → знаки                   | `2 != 3` → `2 ≠ 3`                                           |        |
| `thin_space_triads` | `⎵` между уже разделёнными триадами                    | `1 234 567` → `1⎵234⎵567`                                    |        |
| `nbsp_numero`       | `⎵` между `№` и числом                                 | `№ 7` → `№⎵7`                                                |        |
| `nbsp_section`      | `⎵` между `§` и числом                                 | `§ 12` → `§⎵12`                                              |        |

- `minus` срабатывает в начале текста или строки, после `(`, `:`, `;` или русского слова от трёх букв. Не меняет `1-5`, `10-5`, `10 - 5`, `x -5`, `a = -5`, диапазоны и знак внутри `sup`, `sub`, `small`. Читает дроби и их числовые ссылки: `-1/3` (с `fraction_extended`), `-⅓`, `-&#8531;`, `-&#x2153;` → `−⅓`, при `entities: true` — `&minus;&#8531;`; `-½` → `−½`; без `fraction_extended` `-1/3` → `−1/3`.
- `fraction_extended` не меняет части дат и идентификаторов, длинные дроби и дробь перед знаком дюйма.
- `prime` не меняет `'5'`, `5''`, число в пути, URL, версии или идентификаторе.
- При `entities: true` дроби `fraction_extended`, `′` и стрелки `arrows_extended` выходят числовыми ссылками (`&#8531;`), в `plain`, значениях форматов данных и выбранных атрибутах — Unicode. Повторная обработка их не портит.
- `sub` — только у однобуквенного основания: `a_12` → `a<sub><small>12</small></sub>`; `utf_8`, `log_2`, `file_2.txt`, `snake_case_2` не меняются.

| `trim_line_end`                      | Без пробелов в конце текста                   | `Корвин уходит␣␣␣` → `Корвин уходит` (`input: 'markdown'`)   |       |

| `trim_before_parenthetical_ellipsis` | Без пробела перед `…` в конце скобок          | `(Корвин ушёл …)` → `(Корвин⍽ушёл…)`                         |       |
| `space_after_year`                   | Пробел после года                             | `2024год` → `2024⍽год`                                       |       |

| `nbsp_organization`          | `ООО`, `ЗАО` и т. п. к названию                                                                  | `ООО Амбер` → `ООО⍽Амбер`                |          |

- Правила от `nbsp_magnitude_spaced` до `nbsp_organization_extended` выполняются после остальных правил группы, читают горизонтальные пробелы, включая NBSP, и не пересекают перевод строки: `5760л. с.` → `5760⍽л.⍽с.` за один проход. Числовые привязывают только разделённые формы: склеенные `12шт.`, `5кВт` и идентификаторы не меняют. `nbsp_si_unit` и `nbsp_currency_code` не начинают число с хвоста после `⎵`.
- `nbsp_magnitude_spaced`: вторая привязка — только к валюте или счётной единице: `1,5 млн рублей` → `1,5⍽млн⍽рублей`, `5 тыс. деревьев` → `5⍽тыс. деревьев`.
- `nbsp_count_unit`, `nbsp_si_unit`, `nbsp_currency_code` учитывают регистр: `5 секция`, `5 вТ`, `100 usd`, `100 USDT`, `100USD` не меняются.
- `nbsp_title` допускает заглавную первую букву титула; `св. мощи` не меняется. `nbsp_part`: `т.` и `ч.` только строчные (`Т. 2` — инициал); `т. е.` и `табл. 3D` не меняются.
- `nowrap_because` ставит обёртку `nowrap` или NBSP, как `nowrap_ie`; допускает `т.к.`, сохраняет заглавную первую букву, требует конечную точку и границу слова.
- `currency` не считает `$` знаком валюты в аргументах printf: `за %1$s`, `%2$d из %1$s` не меняются. `долл. США` остаётся словом: `10 долл. США` → `10⍽долл. США`.
- `nowrap_etc` читает `и тд` как `и т. д.`: тире после него стоит как после конца предложения, а при `html: false` следующее число привязывается: `и тд 1` → `и⍽т.⍽д.⍽1`, `и тд — с` → `и⍽т.⍽д. —⍽с`.
- `nbsp_currency_prefix` привязывает и знак после числа, если за ним идёт число: `3 руб. 20 коп.` → `3⍽₽⍽20⍽коп.`.

- `nbsp_single_initial`, `nbsp_after_number`, `nbsp_last_word` и `nowrap_phone_extended` выполняются после остальных правил группы.
- `nbsp_single_initial`: русский однобуквенный инициал или `Дж.`, до четырёх инициалов перед фамилией (`А. Пушкин` → `А.⍽Пушкин`); точек не добавляет, перевод строки не пересекает.
- `nbsp_after_number` считает числом и дробь: `½ стакана` → `½⍽стакана`. Не привязывает латинские слова, склеенные идентификаторы, части дробей через `/`, хвосты телефонов, `уе`, число после `⎵` и сразу после закрывающего строчного тега.
- `nbsp_last_word`: конец абзаца — конец фрагмента, пустая строка или закрывающий блочный элемент. Предыдущим словом не считаются одиночный перевод строки, число, латинское слово и тире.
- `nowrap_phone_extended`: `+7 (999) 123 45 67`, `8-800-555-35-35`, `+7-999-123-45-67`, написание сохраняется; без HTML пробелы становятся NBSP, дефисы остаются. Цифра или буква вплотную с краю отменяет совпадение.
- `nbsp_particle` привязывает ли, бы, б, же, ж к предыдущему слову. В конце текста, перед `!` и `)` — только строчную частицу и только к слову: `Вот же!` → `Вот⍽же!`, `(так ли)` → `(так⍽ли)`, но `а - б` → `а⍽— б`, `зон А и Б` не меняется.
- NBSP после частицы, поставленный `nbsp_short_word`, становится обычным пробелом (`а же в доме` → `а⍽же в⍽доме`), кроме позиции перед тире, двухбуквенной аббревиатурой и коротким словом, которое привязалось бы к своему слову: `вам ли - нет` → `вам⍽ли⍽— нет`, `Вот же НЕ так` → `Вот⍽же⍽НЕ⍽так`, `к б⍽л евро` → `к⍽б⍽л⍽евро`. `nbsp_before_quote` не привязывает кавычку к частице: `вам ли «Амбер»` → `вам⍽ли «Амбер»`.
- `nbsp_short_word` не считает словом серию дефисов: `a --> b`, `a --- b` не меняются.
