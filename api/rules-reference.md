# Правила

Каждое преобразование входит в группу правил — набор замен по регулярным выражениям на одну тему. Двенадцать встроенных групп выполняются в фиксированном порядке:

```
quote → dash → symbol → punctuation → number → space → abbr → nobr → date → hanging → other → text
```

Порядок не меняется: `quote` идёт первой, чтобы тире не мешали распознаванию кавычек; `text` — последней, поскольку оборачивает уже типографированный текст в абзацы и переносы строк.

Правило переключается по идентификатору через [`rules`](configuration.md); там же — синтаксис селекторов, семантические наборы и порядок применения ключей:

```js
microtypo(text, {
  rules: { 'punctuation.comma_before_conjunction': true, 'text.paragraphs': false }
});
```

Флаги в таблицах ниже: `enabled: false` — правило выключено по умолчанию; `cycled` — повторяется, пока текст не перестанет меняться (до 100 итераций за проход); `html-only` — выдаёт разметку (`<sub>`/`<sup>`) и потому пропускается при `html: false`. Столбец «Описание» — метаданные правила из его определения.

## quote — Кавычки

| Правило           | Описание                                                                       | Флаги |
| ----------------- | ------------------------------------------------------------------------------ | ----- |
| `around_link`     | Кавычки вынесены за тег &lt;a&gt;                                              |       |
| `open`            | Открывающая кавычка                                                            |       |
| `open_cyrillic`   | Приклеенная кавычка у кириллицы → « с пробелом                                 |       |
| `close`           | Закрывающая кавычка                                                            |       |

| `swap_exclamation_question`   | Перестановка !? → ?!                                           |                  |

| `trim_bracket_terminal_punct` | Удаление случайной пунктуации перед закрывающей скобкой        |                  |

| `space_before_bracket`        | Пробел перед открывающей скобочкой                             |                  |
