# Правила

Каждое преобразование входит в группу правил — набор замен на одну тему. Двенадцать встроенных групп выполняются в фиксированном порядке:

```
quote → dash → symbol → punctuation → number → space → abbr → nobr → date → hanging → other → text
```

Порядок не меняется: `quote` идёт первой, чтобы тире не мешали распознаванию кавычек; `text` — последней, поскольку размечает абзацы и переносы строк в уже типографированном тексте.

Правило переключается по идентификатору через [`rules`](configuration.md); там же — синтаксис селекторов, семантические наборы и порядок применения ключей:

```js
microtypo(text, {
  rules: { 'punctuation.comma_before_conjunction': true, 'text.paragraphs': false }
});
```

Флаги в таблицах: `enabled: false` — правило выключено по умолчанию; `cycled` — повторяется, пока текст не перестанет меняться (до 100 итераций); `html-only` — работает только при `html: true`.

## quote — Кавычки

| Правило           | Описание                                                                             | Флаги |
| ----------------- | ------------------------------------------------------------------------------------ | ----- |
| `around_link`     | Кавычки выносятся за пределы ссылки `<a>`                                            |       |
| `open`            | Открывающая кавычка                                                                  |       |
| `open_cyrillic`   | Кавычка, примыкающая к кириллице, → « с пробелом перед ней                           |       |
| `close`           | Закрывающая кавычка                                                                  |       |
| `fix_orphan_open` | Открывающая кавычка, примыкающая к концу слова перед пробелом или концом текста, → » |       |
| `nested`          | Вложенные кавычки-«лапки» и знак дюйма                                               |       |

## dash — Дефисы и тире

| Правило                | Описание                                                      | Флаги |
| ---------------------- | ------------------------------------------------------------- | ----- |
| `em_double_hyphen`     | Двойной дефис → тире                                          |       |
| `en_range`             | Диапазон чисел с пробелами вокруг дефиса: «12 - 19» → «12–19» |       |
| `em`                   | Тире после слова, кавычки, скобки или знака препинания        |       |
| `em_line_start`        | Тире в начале строки                                          |       |
| `em_after_sentence`    | Тире после !, ? и многоточия                                  |       |
| `compound_preposition` | Дефис в составных предлогах: из-за, из-под                    |       |
| `indefinite_pronoun`   | Дефис в неопределённых местоимениях                           |       |
| `hyphenated_particle`  | Дефис с частицами: кое-как, кой-кого, всё-таки                |       |
| `emphatic_particle`    | Дефис с усилительными частицами -ка, -кась, -тка, -тко, -де   |       |

## punctuation — Пунктуация

| Правило                       | Описание                                             | Флаги            |
| ----------------------------- | ---------------------------------------------------- | ---------------- |
| `comma_before_conjunction`    | Запятая перед «а» и «но»                             | `enabled: false` |
| `repeat_limit`                | Повтор ! и ? — один знак или три: !! → !, !!!! → !!! |                  |
| `collapse_repeated`           | Повторные запятые, двоеточия и точки с запятой       | `cycled`         |
| `ellipsis`                    | Три и более точки → многоточие                       |                  |
| `mark_ellipsis`               | Многоточие после ? или ! теряет точку: ?… → ?..      |                  |
| `swap_exclamation_question`   | !? → ?!                                              |                  |
| `drop_terminal_garbage`       | Лишняя пунктуация после конечного знака предложения  |                  |
| `collapse_doubled`            | Сдвоенные знаки препинания → одиночные               |                  |
| `trim_bracket_terminal_punct` | Случайная пунктуация перед закрывающей скобкой       |                  |
| `bracket_spaces`              | Лишние пробелы внутри скобок                         |                  |
| `space_before_bracket`        | Пробел перед открывающей скобкой                     |                  |
| `period_at_end`               | Точка в конце текста, если её нет                    | `enabled: false` |

## number — Числа, дроби, математические знаки

| Правило             | Описание                                                 | Флаги     |
| ------------------- | -------------------------------------------------------- | --------- |
| `time`              | Время без пробелов вокруг двоеточия: 08 : 59 → 08:59     |           |
| `en_range`          | Среднее тире в диапазоне чисел: 100-500 → 100–500        |           |
| `minus_range`       | Минус в диапазоне через многоточие: -5…10 → −5…10        |           |
| `times`             | Знак умножения в размерах: 10x12 → 10×12                 | `cycled`  |
| `sub`               | Нижний индекс                                            | html-only |
| `sup`               | Верхний индекс                                           | html-only |
| `fraction`          | Дроби 1/2, 1/4, 3/4 → символы (кроме дюймов)             |           |
| `math`              | Математические знаки: !=, <=, >=, ~=, +-                 |           |
| `thin_space_triads` | Узкий неразрывный пробел между уже разделёнными триадами |           |
| `nbsp_numero`       | Узкий неразрывный пробел между № и числом                |           |
| `nbsp_section`      | Узкий неразрывный пробел между § и числом                |           |

## space — Пробелы

| Правило                              | Описание                                                    | Флаги |
| ------------------------------------ | ----------------------------------------------------------- | ----- |
| `nbsp_two_letter`                    | Неразрывный пробел перед двухбуквенной аббревиатурой        |       |
| `trim_before_punctuation`            | Без пробела перед знаком препинания                         |       |
| `space_after_comma`                  | Пробел после запятой                                        |       |
| `space_after_punctuation`            | Пробел после знаков препинания, кроме точки                 |       |
| `space_after_period`                 | Пробел после точки                                          |       |
| `space_after_ellipsis`               | Пробел после ?.. и !..                                      |       |
| `collapse_spaces`                    | Повторные пробелы и табуляции → один пробел                 |       |
| `strip_quote_padding`                | Без пробелов после открывающей и перед закрывающей кавычкой |       |
| `trim_before_percent`                | Без пробела перед %                                         |       |
| `nbsp_before_quote`                  | Неразрывный пробел перед открывающей кавычкой               |       |
| `nbsp_before_month`                  | Неразрывный пробел между числом и месяцем                   |       |
| `trim_line_end`                      | Без пробелов в конце текста                                 |       |
| `no_space_after_opening_ellipsis`    | Без пробела после многоточия за открывающей кавычкой        |       |
| `trim_before_parenthetical_ellipsis` | Без пробела перед многоточием в конце скобок                |       |
| `space_after_year`                   | Пробел после года                                           |       |

`collapse_spaces` не трогает отступ в начале строки в форматах `text` и `html`: он сохраняется байт-в-байт — см. [Конфигурацию](configuration.md#input-строка-и-объект).
